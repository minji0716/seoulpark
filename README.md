## 팀원
- 20816 이상현 / 20822 장민지
## 질문
"서울시 공원은 면적과 시설 등의 특성에 따라 어떤 유형으로 분류되는가"
## 왜 이 주제인가 (팀이 씁니다)
두 명 모두 데이터 분석과 시각화에 관심이 있습니다. 서울에 있는 공원들을 살펴보면 공원마다 면적과 시설, 위치 등의 특징이 서로 다릅니다. 우리는 이러한 차이를 단순히 개별적으로 비교하는 것보다 데이터를 활용해 비슷한 특징을 가진 공원끼리 분류해 보면 흥미로운 결과를 얻을 수 있을 것이라고 생각했습니다. 그래서 머신러닝의 군집분석을 활용해 서울시 공원의 유형을 분류하고, 공원들의 특징과 지역별 분포를 분석하고자 했습니다.

20816 이상현: 공원마다 면적과 시설이 다르므로 데이터를 활용해 특징을 객관적으로 비교하고, 머신러닝으로 비슷한 특징을 가진 공원끼리 분류하고 싶었다.

20822 장민지: 공원 유형을 시각화하여 서울시 공원들의 특징과 지역별 분포를 쉽게 파악하고 싶었다.
