# 4차시 기록: 데이터 살펴보기

## 20816 이상현
- 오늘 결정한 것: 서울시 주요 공원현황 데이터를 깃허브에 올리고 분석에 활용하기로 했다.
- AI에게 보낸 프롬프트(원문): 서울시 공원 데이터를 깃허브에 올리고 Streamlit에서 불러오는 방법을 알려줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 알려준 코드에서 데이터 주소 부분을 실제 깃허브 Raw 주소로 바꾸었다. 예시 주소는 우리 데이터에 맞지 않았기 때문이다.
- 느낀 점: AI를 활용하면 코드를 쉽게 만들 수 있지만 실제 데이터에 맞게 수정하는 과정도 중요하다고 느꼈다.
- AI 없이 내가 스스로 한 것: 깃허브에 CSV 파일을 업로드하고 저장된 파일을 확인했다.

## 20822 장민지
- 오늘 결정한 것: 공원 데이터를 이용해 공원들의 면적과 시설 등 여러 특징을 비교하기로 했다.
- AI에게 보낸 프롬프트(원문): 서울시 공원 데이터를 분석할 때 어떤 열을 활용하면 좋을지 알려줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 추천한 열 중 실제 데이터에 없거나 분석 목적과 관련이 적은 항목은 제외했다.
- 느낀 점: 데이터를 분석하기 전에 데이터에 어떤 정보가 들어 있는지 확인하는 것이 중요하다는 것을 알게 되었다.
- AI 없이 내가 스스로 한 것: CSV 파일을 직접 열어 데이터의 내용과 열 이름을 확인했다.
